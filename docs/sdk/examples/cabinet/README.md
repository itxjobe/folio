# Cabinet sample package

A `tweakBundle` package that turns on Cabinet, Folio's built-in tweak that shows an app's shortcuts, notifications and music controls, on both screens. Use it as a starting point for your own package.

## Images

Put images in `assets/`: `icon.png` (180 px or larger, square), `hero.webp`, `cover.webp` and `inner.webp`.
They're screenshots from a real phone, so they aren't in the repository. `folio-pkg validate` reports any that are missing.
